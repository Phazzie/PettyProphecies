# AI Service Integration Guide

## Overview

This guide explains how to enable and use the xAI Grok AI service integration for generating passive-aggressive tarot readings.

## What Was Integrated

The existing `xAI Grok` service (`src/services/aiTarot.ts`) has been integrated into the tarot reading flow:

### 1. **AI Service** (`src/services/aiTarot.ts`)
- Generates dynamic, personalized passive-aggressive tarot readings
- Uses `grok-4-fast-reasoning` model via OpenAI SDK
- Gracefully falls back to template readings when unavailable
- **No changes required** - service was already correctly implemented

### 2. **API Endpoint** (`src/pages/api/tarot-reading.ts`)
- **POST** endpoint now supports `useAI` parameter
- Calls `generateAIReading()` when AI is enabled and available
- Automatically falls back to template readings on errors
- Saves `aiGenerated` flag with each reading
- Returns AI model information when AI is used

### 3. **Frontend Component** (`src/components/TarotReading.tsx`)
- Added "Use AI Reading" toggle checkbox
- Shows AI badge when reading is AI-generated
- Displays loading spinner during AI generation
- Handles errors gracefully

### 4. **Database Model** (`src/models/Reading.ts`)
- Added `aiGenerated` field (boolean) to track AI vs template readings
- Defaults to `false` for backward compatibility

## Enabling AI Readings

### Step 1: Set Environment Variable

Add your xAI API key to `.env.local`:

```bash
# Server-side (required for AI to work)
XAI_API_KEY=your-xai-api-key-here

# Client-side (optional - enables AI toggle by default)
NEXT_PUBLIC_XAI_AVAILABLE=true
```

### Step 2: Restart Development Server

```bash
npm run dev
```

### Step 3: Verify AI is Working

1. Navigate to the tarot reading page
2. Check the "Use AI Reading" checkbox (should be checked by default if `NEXT_PUBLIC_XAI_AVAILABLE=true`)
3. Select a spread and submit
4. You should see:
   - A longer, more personalized reading
   - An AI badge showing "Generated by AI (xAI Grok)"
   - More loading time (AI calls take 2-5 seconds)

## How It Works

### Flow Diagram

```
User submits form with useAI=true
        ↓
API checks isAIAvailable()
        ↓
   AI Available?
     /        \
   YES        NO
    ↓          ↓
generateAIReading()  spread.interpret()
    ↓          ↓
    ↓     (fallback)
    ↓          ↓
Save with aiGenerated flag
    ↓
Return reading + modelInfo
```

### Default Behavior

- **With XAI_API_KEY set**: AI is used by default (`useAI=true`)
- **Without XAI_API_KEY**: Template readings are used
- **If AI call fails**: Automatically falls back to template readings

### Fallback Strategy

The integration includes robust error handling:

1. **No API Key**: Uses template reading, logs warning
2. **API Timeout**: Falls back to template, logs error
3. **Malformed Response**: Falls back to template, logs error
4. **Empty Response**: Falls back to template

## API Usage

### Creating a Reading with AI

```typescript
POST /api/tarot-reading
{
  "spreadName": "Maybe It's Not Them, It's You",
  "useAI": true  // Optional: defaults to true if AI is available
}

Response:
{
  "reading": [...cards],
  "interpretation": "Oh look, The Fool and The Magician...",
  "readingId": "reading-123",
  "aiGenerated": true,
  "modelInfo": {
    "available": true,
    "model": "grok-4-fast-reasoning",
    "provider": "xAI Grok"
  }
}
```

```typescript
POST /api/tarot-reading
{
  "spreadName": "Maybe It's Not Them, It's You",
  "useAI": false
}

Response:
{
  "reading": [...cards],
  "interpretation": "Your Perception: Oh look at you...",
  "readingId": "reading-123",
  "aiGenerated": false
}
```

## Migration Path for Existing Readings

Existing readings in the database will continue to work:

- `aiGenerated` field defaults to `false`
- No migration required for existing data
- New readings automatically include the field

### Optional: Backfill Script

If you want to mark all existing readings as template-generated:

```typescript
// migrations/backfill-ai-generated.ts
import { connectToDatabase } from '../src/utils/database'
import { Reading } from '../src/models/Reading'

async function backfill() {
  await connectToDatabase()

  const result = await Reading.updateMany(
    { aiGenerated: { $exists: false } },
    { $set: { aiGenerated: false } }
  )

  console.log(`Updated ${result.modifiedCount} readings`)
}

backfill()
```

**Solution**:

**Solution**:

- Restart dev server
- Clear browser cache
